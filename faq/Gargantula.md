# Gargantula
### Does tapping to free a trapped minion count as interacting with the realm?
Yes, tapping to free a minion from its cocoon is activating a special ability, and counts as interacting with the realm.
### If the minion is not dragged to Gargantula's location, does it still get disabled? What if the minion is already at Gargantula's location?
Gargantula must be at the same location as the minion to wrap it in her web, so if the minion cannot be dragged there it will not be disabled. However, if it already shares a location with Gargantula, she will cocoon it.
