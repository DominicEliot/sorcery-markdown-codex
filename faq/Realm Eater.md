# Realm Eater
### How does this ability work?
Whenever ))Realm-Eater(( attacks a site and strikes it, that site is destroyed and the ))Realm-Eater(( gains an ongoing effect causing it to be immobile. You can activate ))Realm-Eater's(( digest ability to remove one instance of this immobilizing effect, but if you have attacked and destroyed multiple sites you must digest each one.
### What happens if Realm-Eater cannot be immobilized due to some effect (e.g. Tabula Rasa, Onslaught)?
For as long as the effect is being applied, ))Realm((-Eater can ignore the ongoing effect caused by eating sites. If that effect is removed, ))Realm((-Eater will no longer be immune to the lethargy caused by eating so much, and will be immobilized if they have not cleared the ongoing effects by digesting the sites.
