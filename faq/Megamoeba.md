# Megamoeba
### If I play Dodge Roll on my Megamoeba, does the attack still go through because the Megamoeba is still occupying the original location?
Yes, the target is still valid, but Megamoeba now has +1 power from the extra location it occupies thanks to Dodge Roll.
### If my opponent uses an effect that moves sites (e.g. Atlas Wanderer, Earthquake, etc.), what happens?
Megamoeba moves with the site. Megamoeba is mostly treated a normal size unit for movement effects.
### If Megamoeba starts at 2 power, can it move into Gnome Hollows (thus getting to 3 power)?
Yes. First, Megamoeba enters, then it grows in power immediately after entering.
### What happens if Megamoeba is the target of Whirling Blades?
The Megamoeba moves 2 steps by extending a pseudopod twice (possibly from two different starting locations), and gains 2 power. Then, it strikes all enemies in the starting and destination locations of the pseudopods that took the steps.
### When the Megamoeba is teleported, does its passive ability still apply?
Yes. A single pseudopod enters the teleportation destination, and the Megamoeba can become a single oversized unit that spans non-adjacent squares. The Megamoeba is weird.
### What happens if Megamoeba is in a Silence aura?
As soon as it enters the Silence aura, it loses its abilities, but size is considered a characteristic and thus persists. Therefore, it continues to occupy all the locations, but it doesn't get the +1 power per location. It will move like any other oversized unit (albeit potentially strangely shaped).
### Can Megamoeba declare a movement to a location it already occupies? (e.g. if it wanted to move an artifact it was carrying)
Yes. Megamoeba is weird.
### What happens when Megamoeba gets pulled / pushed?
Choose a specific location it occupies and pull / push a single pseudopod from there.
### If the Megamoeba occupies a site with an enemy, can the Megamoeba take the Move and Attack basic ability to move first, and then attack that original enemy, thus growing in power beforehand?
Yes.
### If the Megamoeba occupies a site with an enemy, and the Megamoeba moves to a different site without attacking, can the enemy intercept?
Yes! If Megamoeba uses Move and Attack, then doesn't attack, any enemy that shares a location with them may tap to intercept.
### What happens if Megamoeba gains burrow or submerge?
It can occupy both the surface location and the subsurface location on a site, and each occupied location will grant +1 power, per card text. 40 power Megamoeba, here we come!
### What happens if Megamoeba is forcefully burrowed or submerged without the burrow or submerge ability?
If any part of unit occupies an inhospitable location, it dies. So, the Megamoeba would die in this case.
### What happens when the Megamoeba gets carried?
It occupied all the locations it was carried through.
