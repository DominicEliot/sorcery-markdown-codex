# Hyperparasite
### Is the minion only disabled while being carried?
Yes, if the minion is no longer carried, it is no longer disabled.
### What happens if the Hyperparasite is Silenced or Disabled while carrying a minion?
As per the rules about Carrying Units, if this loses its ability to carry a minion, that minion is no longer carried, and no longer disabled by this ability.
### Can this choose to drop the minion it is carrying?
Yes, abilities which allow a unit to pick up other units also allow them to drop them.
### If this stops carrying a minion can it pick up another minion?
Yes, it can pick up another minion, or the same minion again.
### Can this be moved by force while carrying a minion?
Yes.  It cannot take its own steps while carrying a minion.  It can still be moved by force.
