# The Colour Out Of Space
### If it’s not adjacent to void and is within Abundance, does it still gain extra mana?
Yes. The site doesn't provide mana normally, but if it's modified in some way (e.g. Abundance), then it can provide additional mana. 0 + 1 = 1.
### If it’s not adjacent to void and is the target of a flood, does it still gain water affinity?
Yes. The site doesn't provide affinity normally, but if it's modified in some way (e.g. Flood), then it will.
